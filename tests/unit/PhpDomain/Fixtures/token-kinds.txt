# Every token kind the tokenizer extension defines that this parser has been checked against.
# `MethodNameServiceTest::testNoUnexaminedTokenKindExists()` fails when a PHP version defines
# one that is not here, because that is how each of the version-dependent readings this class
# used to have arrived: a kind that merges text an earlier version lexed apart.
#
# A new name here is a question, not a defect. If the kind merges text, handle it in
# `MethodNameService::normaliseMergedTokens()` and record a signature in `token-streams.txt`;
# if it does not, add the name below.
#
# Recorded from PHP 8.1 through 8.5. Of the six added since 8.1, five merge text and are
# undone: T_PIPE and T_VOID_CAST (8.5), T_PRIVATE_SET, T_PROTECTED_SET and T_PUBLIC_SET (8.4).
# T_PROPERTY_C (8.4) does not: `__PROPERTY__` is one token under either name.
